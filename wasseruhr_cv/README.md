# Wasseruhr-CV

Liest eine Wasseruhr per OpenCV-Template-Matching ab, ohne LLM und ohne Cloud.

- Lernseite und Verwaltung in der Seitenleiste: anlernen, nachtrainieren,
  Lernbilder korrigieren und löschen, Vorlagen ansehen
- Modell als ZIP exportieren und importieren
- „Kamera jetzt ablesen“ über die Home-Assistant-API
- Einfache HTTP-API (`POST /ablesen`), fertiger Node-RED-Flow im Repository

Einrichtung und Bedienung stehen im Reiter **Dokumentation**.
