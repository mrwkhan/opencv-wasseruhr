# Wasseruhr-CV

Reads a water meter with a camera and OpenCV template matching, without LLM
and without cloud, and writes the checked meter reading to Home Assistant.

- Standalone: reads every few minutes on its own and writes only certain,
  plausible values to a sensor (Energy dashboard) and optionally a helper
- Initial model included, training and admin pages in the sidebar
- English and German: the pages follow your browser (switch DE/EN on the
  page), log and sensor follow Home Assistant
- Optionally reachable in the local network via HTTP and/or HTTPS

Setup and usage: tab **Documentation**.

---

Liest eine Wasseruhr per Kamera und OpenCV-Template-Matching ab, ohne LLM und
ohne Cloud, und schreibt den geprüften Zählerstand nach Home Assistant.

- Eigenständig: liest alle paar Minuten selbst ab, schreibt nur sichere und
  plausible Werte in einen Sensor (Energie-Dashboard) und optional einen Helfer
- Initiales Modell eingebaut, Lernseite und Verwaltung in der Seitenleiste
- Deutsch und Englisch: Seiten folgen dem Browser (Umschalter DE/EN auf der
  Seite), Protokoll und Sensor folgen Home Assistant
- Optional erreichbar im Heimnetz per HTTP und/oder HTTPS

Einrichtung und Bedienung: Reiter **Dokumentation**.
